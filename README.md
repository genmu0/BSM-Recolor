A repository of source files for Boolean Statistical Mechanics, an independently produced mathematics monograph.
Download the most recent version for free here: (Boolean Statistical Mechanics v105.pdf)


A paperback and hardcover version of this text is available for print-on-demand from Amazon via Kindle Direct Publihsing.

The textbook primarily uses the Okabe-Ito color scheme for its 188 diagrams in order to maintain colorblind friendliness. Approximately 1 in 12 males and 1 in 200 females have some level of colorblindness.
